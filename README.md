# College Fee Management System

A terminal-based **College Fee Management System** developed in C for managing student fee records from the administrator's side. The system uses **file handling for persistent data storage** and provides a simple command-line interface for performing common fee management operations.

## Features

### Admin Authentication
- Admin login system
- New admin registration
- Credential-based access to the management system

### Student Management
- Add new student records
- Search for students
- Display all registered students
- Delete student records

### Fee Management
- Record student fee payments
- Update fee records
- Track total fees, paid fees, and pending dues

### Reports & Sorting
- Generate fee management reports
- View payment and pending-fee summaries
- Sort students based on pending fees

## Tech Stack

| Component | Technology |

## Application Flow

### Authentication

```text
1. Login
2. Register New Admin
```

After successful authentication, the administrator can access the main management menu.

### Main Menu

```text
1. Add Student
2. Pay Fees
3. Display Students
4. Search Student
5. Delete Student
6. Sort by Pending Fees
7. Generate Report
8. Exit
```

## Data Persistence

The system uses **C file handling** to store and retrieve records, allowing student and fee information to persist even after the program is closed.
